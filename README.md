# 教育部「智慧健康產業跨領域生技人才培育計畫」精準醫療領域網站

這個資料夾是可直接部署到 GitHub Pages 的靜態網站版本。

## 檔案

- `index.html`：網站首頁
- `styles.css`：版面與響應式樣式
- `script.js`：導覽、捲動顯示、課程篩選互動
- `assets/`：網站使用的 SVG 圖與團隊架構圖

## GitHub Pages 部署

1. 在 GitHub 建立新的 repository，例如 `tmu-partner-school`。
2. 將此資料夾內所有檔案上傳到 repository 根目錄。
3. 進入 repository 的 `Settings` → `Pages`。
4. Source 選 `Deploy from a branch`。
5. Branch 選 `main`，資料夾選 `/root`。
6. 儲存後等待 GitHub 產生網址。

部署網址通常會是：

```text
https://你的帳號.github.io/tmu-partner-school/
```
